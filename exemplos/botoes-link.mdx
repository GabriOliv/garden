# Botões de link

Opções para as duas ações de destaque. Todas continuam um `<a>`: navegam, abrem em nova aba e são lidas como link.

- **A**: o `Button` `solid` do Dossier. Destaque máximo, mas texto pequeno (mono, 12 px).
- **B**: igual ao A, com a seta dizendo "vai para outra página". A seta anda 4 px no hover.
- **C**: no tamanho dos títulos de seção (32 px, maiúsculas), com fio azul embaixo e seta. É a mesma voz do h2 dos artigos.

O `Button` `outline` do Dossier, com seta. Cada um ganha `aria-label` com o destino, porque o texto se repete.

	</Stack>
	<Stack gap={3}>
		<h3 className="ds-t-heading">CT-TAS - Test Automation Strategy</h3>

		<Link className={`ds-t-label ds-btn ds-btn-outline ${s.btn}`} to="/docs/istqb/cttas" aria-label="Leia mais sobre CT-TAS">Leia Mais<Icon name="arrow-right" className={s.arrow} /></Link>

### B · card inteiro clicável

Sem "Leia Mais": o título é o link e o clique vale no card todo. O fundo muda no hover e a seta anda. O link tem o nome do curso, sem `aria-label`.

### C · índice (`Contents` do Dossier)

Os cards viram linhas de um sumário numerado; o título é o link. Os números contam a ordem: CTFL vem antes de CT-TAS. Sai a imagem do card.
